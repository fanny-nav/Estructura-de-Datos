Paso 1: Abrir el ProyectoAbra Visual Studio Code.Vaya a Archivo > Abrir Carpeta... (File > Open Folder...) y seleccione la carpeta que contiene sus archivos del proyecto (donde se encuentran asm_to_binary.py y los archivos .asm).

Paso 2: Ejecutar el ScriptPuede lanzar el decodificador utilizando cualquiera de estos dos métodos nativos de VS Code:Método A: Usando la Terminal Integrada (Recomendado)Abra la terminal integrada de VS Code yendo al menú superior Terminal > Nueva Terminal (o usando el atajo Ctrl + ñ / `Ctrl + Shift + ``).Asegúrese de que la terminal está ubicada en la carpeta del proyecto.Escriba el siguiente comando y presione Enter:Bashpython asm_to_binary.py
(Nota: En algunos sistemas operativos como macOS o ciertas distribuciones de Linux, el comando puede ser python3 asm_to_binary.py).Método B: Usando el botón de EjecuciónEn el panel izquierdo (Explorador), haga doble clic sobre el archivo asm_to_binary.py para abrirlo en el editor.Haga clic en el botón de "Play" (Ejecutar archivo de Python) ubicado en la esquina superior derecha de la ventana de VS Code.

Paso 3: Uso de la Interfaz Gráfica (GUI)Al ejecutar el script, se abrirá automáticamente una ventana flotante con la interfaz del ensamblador.  Haga clic en "📂 Cargar .asm" para seleccionar su archivo fuente (ej. multiplicacion.asm). Alternativamente, use el botón "▶ Ejemplo integrado" para cargar automáticamente el algoritmo de prueba.  Haga clic en "⚙ Ensamblar -> Binario" para realizar la traducción de dos pasadas. Verá el código formateado de 32 bits en el panel derecho.  Haga clic en "💾 Guardar .txt". El nuevo archivo binario aparecerá inmediatamente en el panel explorador de VS Code, a la izquierda.
